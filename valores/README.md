# Calculadora de valores · JMor

Aplicación web autónoma para estimar y registrar una operación con acciones: importe invertido, comisiones, resultado, rentabilidad, precio de equilibrio y precio de venta sin pérdida. No compara escenarios.

## Acceso y uso en iPhone

Abrir https://josepmor.github.io/datasets/valores/ en Safari. Para instalarla: Compartir → Añadir a pantalla de inicio → Abrir como app web → Añadir. Abrir una vez con conexión y esperar al estado «Disponible sin conexión» antes de usarla en modo avión.

Los cálculos son locales. Las estimaciones y operaciones se guardan únicamente en el navegador o instalación del dispositivo; no se sincronizan. Se pueden exportar a CSV o hacer copias JSON.

## Publicación y privacidad

GitHub Pages en `JosepMor/datasets`, rama `master`, ruta `/valores/`. No modifica `/prestamos/`.

No incluye dependencias remotas, backend, analítica, envíos ni datos personales de clientes. Los datos que introducen los usuarios no se transmiten. Importes antes de impuestos; no incluye dividendos ni divisas.
